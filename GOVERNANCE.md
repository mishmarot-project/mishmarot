# Governance

## Current Phase: Solo Maintainer

Mishmarot is currently maintained by a single individual. All architectural, data policy, and partnership decisions are made by the maintainer.

## Planned Phase 2: Advisory Board

As partnerships develop, an advisory board of 3–5 people representing community security, academic research, and civil society will be established. The advisory board will guide:

- Data policy and classification decisions
- Partnership priorities and data-use agreements
- Definitional disputes (e.g., edge cases in IHRA application)
- Ethical considerations in data display and access

The advisory board does not make code decisions — those remain with the maintainer and code contributors.

## Planned Phase 3: Fiscal Sponsorship

The long-term goal is fiscal sponsorship through an established entity (e.g., Open Source Collective, Linux Foundation, or a Jewish community foundation) that can:

- Receive grants and philanthropic funding
- Execute data-use agreements with institutional partners
- Provide institutional continuity beyond any single maintainer

## Decision-Making

Until an advisory board is established:

- Technical decisions are made by the maintainer with input from contributors via GitHub issues and discussions
- Data policy decisions are documented in `docs/methodology/` and versioned alongside the code
- Classification decisions follow the taxonomy specification in `docs/taxonomy/`

## Changes to Governance

This document will be updated as the project evolves. All changes are tracked in version control.
