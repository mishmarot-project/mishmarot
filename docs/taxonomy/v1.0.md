# Mishmarot Incident Taxonomy v1.0

## Overview

Mishmarot classifies antisemitic incidents on three independent dimensions, enabling cross-source comparison and multi-framework analysis. This taxonomy is versioned — researchers citing Mishmarot data should reference the taxonomy version to ensure reproducibility.

## Dimension 1: Incident Type (Severity)

What happened. Mapped to ADL (3-tier), CST (6-tier), and RIAS/ENMA (6-tier) systems.

| Code | Label | Severity | Description | ADL Equivalent | CST Equivalent | RIAS Equivalent |
|------|-------|----------|-------------|----------------|----------------|-----------------|
| `extreme_violence` | Extreme Violence | 1 | Murder, attempted murder, bombing, arson with persons present | assault | extreme_violence | extreme_violence |
| `assault` | Assault | 2 | Physical attack causing injury, includes spitting, throwing objects | assault | assault | assault |
| `targeted_damage` | Targeted Damage | 3 | Property destruction, arson without persons, vandalism | vandalism | damage_desecration | targeted_damage |
| `desecration` | Desecration | 3 | Cemetery, memorial, or synagogue desecration | vandalism | damage_desecration | targeted_damage |
| `threat` | Threat | 4 | Direct, credible threat of violence (written or verbal) | harassment | threats | threatening_behaviour |
| `abusive_behaviour` | Abusive Behaviour | 5 | Verbal abuse, slurs, in-person harassment | harassment | abusive_behaviour | offensive_behaviour |
| `propaganda_literature` | Propaganda/Literature | 5 | Flyer distribution, stickering, mass mailings | harassment | literature | mass_mailings |
| `online_abuse` | Online Abuse | 5 | Social media harassment, email abuse, coordinated campaigns | harassment | abusive_behaviour | offensive_behaviour |
| `institutional` | Institutional | 5 | Discriminatory policies, exclusion from services | harassment | — | — |
| `other` | Other | 3 | Does not fit above categories | — | — | — |

## Dimension 2: Antisemitic Manifestation (Ideological Content)

What type of antisemitism was expressed. Aligned with the RIAS five-manifestation model. An incident may be assigned **multiple manifestations** simultaneously (RIAS average: 1.5 per incident).

| Code | Label | Description | Examples |
|------|-------|-------------|----------|
| `modern` | Modern Antisemitism | Conspiracy myths, claims of Jewish control over finance/media/government | "Jews control the banks," "Jewish lobby" |
| `othering` | Antisemitic Othering | Marking Jews as alien, foreign, or not belonging | "Go back to Israel," exclusion from spaces |
| `post_shoah` | Post-Shoah Antisemitism | Holocaust denial, distortion, trivialization | "The Holocaust didn't happen," Nazi imagery/salutes |
| `israel_related` | Israel-Related Antisemitism | Demonization, delegitimization, or double standards applied to Israel as a Jewish collectivity | Holding all Jews responsible for Israeli policy |
| `religious` | Religious Antisemitism | Theological antisemitism, deicide accusations | Blood libel, "Christ-killer" accusations |

## Dimension 3: Explicitness

How overt the antisemitic content is. Aligned with the Decoding Antisemitism framework (King's College London).

| Code | Label | Description |
|------|-------|-------------|
| `explicit` | Explicit | Openly hostile statements with no ambiguity |
| `implicit` | Implicit | Uses known tropes or stereotypes indirectly |
| `coded` | Coded | Dog whistles requiring cultural knowledge to identify (e.g., triple parentheses, "globalist") |
| `ambiguous` | Ambiguous | Context-dependent; reasonable disagreement about whether content is antisemitic |

## Additional Classification Fields

### Setting
Where the incident occurred: `synagogue_jewish_institution`, `campus`, `street_public_space`, `residence`, `workplace`, `school_k12`, `online`, `government_political`, `cemetery_memorial`, `transit`, `other`.

### Confidence Tier
Verification level: 1 (confirmed), 2 (verified), 3 (credible), 4 (unverified). Public display threshold: tier 1–2 by default, tier 3 with visual indicator.

### Definition Framework
Which definition was used for classification: `ihra` (default), `jda`, `source_native`.

## Versioning

This taxonomy is version **1.0**. Changes to category definitions, additions of new categories, or modifications to source mappings will increment the version number. The `source_taxonomy_version` field on each incident records which version was used at ingestion time.
